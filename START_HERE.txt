╔══════════════════════════════════════════════════════════╗
║           NETRIX — HOW TO RUN (IMPORTANT)                ║
╚══════════════════════════════════════════════════════════╝

  DO NOT open the .html files by double-clicking them.
  That causes "File not found" and broken {{ url_for }} links.

  The app needs the Python server running.

────────────────────────────────────────────────────────────
  WINDOWS
────────────────────────────────────────────────────────────
  1. Double-click   start.bat
  2. Wait until you see "Running on http://127.0.0.1:5000"
  3. Open Chrome/Firefox at:   http://127.0.0.1:5000

────────────────────────────────────────────────────────────
  MAC / LINUX
────────────────────────────────────────────────────────────
  1. Open Terminal in this folder
  2. Run:   chmod +x start.sh && ./start.sh
  3. Open:  http://127.0.0.1:5000

────────────────────────────────────────────────────────────
  MANUAL
────────────────────────────────────────────────────────────
  python -m venv venv
  venv\Scripts\activate          (Windows)
  source venv/bin/activate       (Mac/Linux)
  pip install -r requirements.txt
  python run.py
